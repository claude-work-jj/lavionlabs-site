개인정보처리방침

최종 업데이트: 2026년 9월 29일 | 적용 대상: LAVION 개인비서 앱 (Windows 데스크톱)

요약: 이 앱은 회사 서버를 운영하지 않습니다. 사용자의 업무 데이터(할 일, 일정, 이메일 내용 등)는 설치하신 컴퓨터에 저장되며(「다른 PC에서 이어 쓰기」를 켜면 암호화한 사본이 직접 고른 폴더로 갑니다 — 4-2절), LAVION은 이 데이터를 수집·조회·저장하지 않습니다. AI 기능과 캘린더 연동은 사용자가 직접 등록한 본인 계정(Anthropic·OpenAI·Google 등)을 통해 사용자의 기기에서 직접 해당 서비스와 통신합니다. 웹 페이지를 자료로 가져올 때도 사용자의 기기가 그 주소에 직접 접속합니다(4-3절).

1. 이 앱이 회사 서버를 두지 않는다는 것의 의미

LAVION 개인비서 앱은 "로컬 퍼스트" 방식으로 만들어졌습니다. 할 일, 프로젝트, 일정, 이메일에서 추출한 정보 등 사용자가 앱에서 만들거나 가져온 데이터는 사용자의 컴퓨터에 있는 로컬 데이터베이스 파일에 저장됩니다. 사용자가 「다른 PC에서 이어 쓰기」를 켠 경우에만, 그 내용을 암호화한 사본이 사용자가 직접 고른 폴더(예: 구글 드라이브 폴더)에 저장됩니다(4-2절). 이 파일은 LAVION의 서버로 전송되지 않으며, LAVION 임직원은 이 데이터에 접근할 수 없습니다.

2-1. AI 기능 — 사용자 본인의 계정을 사용합니다

이메일에서 일정·업무를 추출하거나 답장 초안을 작성하는 등 AI 기능을 쓰려면, 사용자가 직접 Anthropic(Claude), OpenAI(GPT), Google(Gemini) 중 하나를 선택하고 본인의 API 키를 앱에 등록해야 합니다. 이 기능을 쓸 때 관련 텍스트(이메일 본문 등)는 사용자의 기기에서 사용자 본인의 계정으로 해당 AI 제공사에 직접 전송됩니다. LAVION은 이 통신을 중계하거나 그 내용을 열람하지 않습니다. 각 AI 제공사가 해당 데이터를 어떻게 처리하는지는 각 사의 개인정보처리방침을 따릅니다.

API 키를 아직 등록하지 않은 사용자를 위한 샘플 모드에서는 미리 준비된 예시 데이터만 사용하며, 어떤 AI 서비스와도 통신하지 않습니다.

3. 이메일 접근

사용자가 이메일 계정(IMAP/POP3, Outlook 등)을 앱에 연결하면, 앱은 사용자의 기기에서 사용자의 인증 정보로 직접 메일 서버에 접속해 메일을 가져옵니다. 이 과정은 LAVION 서버를 거치지 않습니다. 답장 초안은 사용자가 명시적으로 요청하고 검토·승인한 뒤에만 저장되며, 앱이 사용자 동의 없이 자동으로 메일을 발송하지 않습니다.

4. Google Calendar 연동

Google Calendar 연동은 별도 동의(OAuth) 절차를 거치며, 언제든 앱 내에서 연결을 해제할 수 있습니다. 연동은 사용자의 기기와 Google API 사이에서 직접 이루어지며, LAVION 서버를 거치지 않습니다.

4-2. 다른 PC에서 이어 쓰기

  • 무엇이 — 앱 데이터 전체(메일 본문·업무·주소록·거래·자료, 그리고 암호화된 상태로 보관된 메일 비밀번호·AI 키·구글 연결 정보)와, 사용자가 켠 경우 첨부 파일. 한 PC에 계정이 여럿이면 모든 계정의 데이터가 포함되며, 켜기 전에 그 사실에 동의를 받습니다.
  • 어디로 — 사용자가 직접 고른 폴더. 이 폴더를 클라우드로 옮기는 것은 사용자가 설치한 클라우드 서비스(Google Drive 등)이며, 그 보관에는 해당 서비스의 약관과 개인정보처리방침이 적용됩니다. LAVION은 이 폴더에 접근하지 않고, 어떤 파일도 받지 않습니다.
  • 어떤 상태로 — 내용은 AES-256-GCM으로 암호화됩니다. 암호화 열쇠는 사용자의 각 PC 안(운영체제 보호 저장소)에만 있고, 클라우드 폴더에는 사용자가 정한 동기화 암호로 잠근 형태로만 놓입니다. 동기화 암호는 어디에도 저장되지 않습니다(LAVION도 모릅니다). 기기 이름(따로 정하지 않으면 ‘PC-1A2B’처럼 자동으로 붙는 이름)·앱 버전·시각·파일 크기·첨부 파일 형식 같은 관리 정보는 암호화되지 않은 채 같은 폴더에 남습니다.
  • 끄기와 지우기 — 설정에서 언제든 끌 수 있습니다. 기능을 꺼도 폴더에 이미 저장된 파일은 자동으로 지워지지 않으며, 필요하면 사용자가 직접 지울 수 있습니다.

4-3. 웹 페이지 가져오기 (자료실)

  • 무엇을 — 사용자가 자료실 「자료 입력」에 웹 주소를 넣으면, 앱이 그 페이지의 본문을 가져와 자료로 담습니다. 이때 사용자의 컴퓨터가 그 주소에 직접 접속합니다. 이 요청은 LAVION 서버를 거치지 않으며, LAVION은 사용자가 어떤 주소를 가져왔는지 알 수 없습니다.
  • 언제 — 주소를 붙여넣으면 앱이 바로 본문을 가져옵니다. 다만 비밀번호 재설정이나 수신거부 링크처럼 여는 것만으로 무언가가 처리될 수 있는 주소는 저절로 열지 않고, 사용자가 「본문 가져오기」를 누를 때만 엽니다.
  • 상대 사이트가 받는 정보 — 일반 웹 브라우저로 방문할 때와 같이, 그 사이트는 사용자의 인터넷 주소(IP)와 일반 브라우저와 같은 형식의 요청 정보를 받습니다. 이 방식의 요청에는 로그인 정보가 실리지 않습니다. 그 사이트가 이 정보를 어떻게 처리하는지는 해당 사이트의 방침을 따릅니다.
  • 로그인이 필요한 페이지 — 앱 안의 별도 「가져오기 창」에서 사용자가 그 사이트에 직접 로그인합니다. harudo는 아이디·비밀번호를 받거나 저장하지 않으며, 사용자가 「이 페이지 가져오기」를 누른 순간의 페이지 내용만 읽습니다. 이 창은 사이트의 알림·위치·카메라 등 권한 요청을 모두 거절합니다.
  • 이 PC에 남는 것 — 다음에 다시 로그인하지 않아도 되도록, 가져오기 창에서 한 로그인 상태(쿠키)와 그 사이트가 남긴 저장 데이터·캐시가 이 PC의 전용 저장 공간에 남습니다. harudo 로그인과는 따로 보관되고, 「다른 PC에서 이어 쓰기」 사본에도 담기지 않으며, 외부로 전송되지 않습니다. 설정 → 「웹 가져오기 창」 → 「가져오기 창 로그아웃」으로 언제든 지울 수 있습니다.
  • 가져온 본문 — 다른 자료와 같이 사용자의 컴퓨터에 저장됩니다. 「다른 PC에서 이어 쓰기」를 켠 경우 그 사본에 포함되고(4-2절), 자료실의 AI 추천을 쓰면 본문 앞부분이 사용자가 선택한 AI 제공사로 전송됩니다(2-1절).

5. 광고 및 추적

현재 버전은 광고나 사용자 추적(analytics)을 포함하지 않습니다. 이 부분이 변경될 경우 이 페이지를 통해 미리 고지합니다.

6. 오류 보고

안정성 개선을 위해 오류 발생 시 진단 정보를 보내는 기능을 도입할 수 있습니다. 이 기능이 추가되면 개인 식별 정보를 제외(마스킹)한 정보만 전송되며, 사용자가 끌 수 있는 옵션을 함께 제공합니다.

6-1. AI 결과 신고

AI가 만든 결과(할 일 제안, 답장 초안, 초안 검토, 체험 모드 결과)가 부적절하거나 잘못됐다고 판단되면 그 화면에서 바로 신고할 수 있습니다. 신고 내용은 먼저 사용자의 기기에만 기록되며, 앱이 자동으로 전송하지 않습니다. 사용자가 화면에서 전문을 확인한 뒤 메일로 보내거나 복사하는 방식으로 직접 전달합니다.

신고에 담기는 것은 AI가 만든 출력의 발췌(개인정보 자동 마스킹 후), 어느 화면·어느 AI 제공사·어떤 모델이었는지, 그리고 사용자가 직접 쓴 설명뿐입니다. 원본 메일의 제목과 본문, 보낸사람·받는사람 주소, 계정 정보, API 키는 신고에 포함되지 않습니다. 보내기 전에 마스킹된 전문을 화면에서 그대로 확인할 수 있고, 원하지 않는 부분은 직접 지운 뒤 보낼 수 있습니다.

6-2. 주소록 (연락처 자동 수집)

앱은 사용자가 주고받은 메일에서 연락처를 자동으로 모읍니다. 상대방의 이메일 주소, 표시 이름, 주고받은 횟수, 마지막 연락 시점이 여기에 해당합니다. 이 정보는 답장 초안의 말투를 정하고 연락처를 정리하는 데 쓰입니다.

이 기록은 사용자의 컴퓨터에만 저장되며 외부로 전송되지 않습니다. LAVION의 서버로 올라가지 않고, 광고나 분석 목적으로 사용되지 않으며, 제3자에게 제공되지 않습니다.

noreply처럼 답장할 수 없는 자동발송 주소는 별도로 분류해 목록에서 감춥니다. 사용자는 앱의 주소록 화면에서 연락처를 삭제할 수 있고, 삭제한 연락처는 이후 메일이 와도 다시 수집되지 않습니다. 전체 목록은 언제든 CSV 파일로 내보낼 수 있습니다.

광고·뉴스레터 메일에 수신거부 정보가 포함된 경우, 앱은 그 경로를 보관했다가 사용자가 요청할 때 해당 발신처의 수신거부 페이지를 열어줍니다. 앱이 사용자를 대신해 수신거부 요청을 보내지는 않습니다.

7. 미성년자

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 이러한 개인정보를 의도적으로 수집하지 않습니다.
